# Contributing

Thanks for improving AI Highlight Reel Maker.

## Development setup

1. Fork or clone the repository.
2. Create a focused branch from `main`.
3. Create and activate a Python 3.11 virtual environment.
4. Install the project with `python -m pip install -e .`.

## Quality checks

Run `python -m pytest` before opening a pull request. Add tests for timeline, media-processing, and error-handling changes. Keep sample assets small and redistributable.

## Pull requests

Describe the problem, implementation, and validation. Never commit credentials, private media, model caches, or generated output.
